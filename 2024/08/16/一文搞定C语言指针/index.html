什么是指针？

首先了解不同数据类型在计算机内存中如何存储，我们谈论内存时一般说的是随机存储器（RAM，也就是主存），当计算机为一个变量分配内存时，首选取决于变量类型，其次取决于编译器。

  • 指针是一个变量，它存放着另外一个变量的地址。

  • 解引用符号*，get the value 获取指针指向的变量值。

指针的类型，算术运算，void指针

  • 指针是强类型的，需要一个特定类型的指针来存放特定类型变量的地址。为什么要把指针设定为强类型？——因为指针不仅用来存储内存地址，还需要用它来解引用那些地址的内容。

  • 算术运算：可以对一个指针变量进行加减操作。

  • void类型指针是一种通用类型指针，在赋值时需要进行强制类型转换。

  • 其中主调函数和被调函数以及其局部变量按照顺序依次存入栈（Stack）中，当调用结束时，从Stack中清除。

指针和数组

  • 数组在内存中连续存储，当对一个指向数组元素的指针进行加减操作时，可以知道其他数组元素的内容。

  • 指针指向数组名，即指向数组首地址/基地址。

  • 访问数组A第i个元素地址：&A[i] 或 A+i

  • 访问数组A第i个元素值：A[i]或*(A+i)

数组作为函数参数

  • 当编译器看到数组作为函数参数时，它不会拷贝整个数组，它仅仅是创建一个同名指针。当函数被调用时，编译器仅拷贝主调函数中数组的首地址。

  • 数组可以很大，如果每次调用都拷贝数组会耗费大量的内存。因此对于数组来说，不使用传值方式，而是使用传引用方式。

指针和字符数组

  • 如何存储字符串？——字符串必须以NUL结束。

  • 字符数组长度要≥字符个数+1。e.g.存储“John”的字符数组长度至少为5字节。

  • 为什么要多一个字符？—— 需要在最后加一个NUL字符（ACII码是0，使用时要加上转义符’\0’来表示）表示字符的结束。

  • sizeof函数获取的是整个字符数组的长度而非字符串的长度，会将空字符计算在内，如果要计算实际字符串的长度需使用strlen 。

  • 数组名不等同于指针
  • 同整型数组一样，字符数组在作为函数参数时，总是采用传引用的方式，编译器仅拷贝数组基地址。

字符串常量和常量指针

  • 以上文打印字符串数组的代码为例，介绍下程序运行时变量/ 数据在内存中的存储。

  • 当程序运行时，首先main函数会被调用。任何函数被调用时，会在内存的栈区开辟一块空间（栈帧：假设地址100-150）来执行该函数。栈是一块连续的内存，地址自下而上分配。

  • 函数的局部变量都会被分配到栈帧， 当main()函数执行时，首先为数组C分配20字节内存（地址100到120）。

  • main()函数调用print()函数，栈中往上开辟一块栈帧（地址150-170）给print()。main函数暂停，执行print函数， print中包含一个局部变量C，C是一个指针变量（地址154），默认占用4字节。此处的C和main函数中的C是不同的变量， C将地址100传给print函数。

  • 传参时用const修饰指针参数即常量指针，该指针指向的变量只能读不能被修改。

栈

首先了解内存架构-操作系统如何管理内存：

  • 栈：任何时候都是栈顶的函数执行，其他函数暂停。等上面的函数返回后，下面的函数才继续执行。 main()函数也返回后，全局变量被销毁。

  • 内存中预留给栈的空间有限制，应用程序在运行期间不能申请更多的栈内存。 当调用程序超过栈空间大小就会导致栈溢出（stackoverflow）。

  • 内存在栈上的分配和销毁有一定的规则，当函数被调用时，它被压入堆栈，当它结束的时候弹出堆栈，如果变量是在栈上分配的，那就不能操作变量的范围。

堆

  • 当我们需要声明一个很大的数据类型，比如一个很大的数组作为局部变量，我们需要在编译期间就知道数组的大小。如果有这样一个需求场景：需要在运行期间根据参数决定数组的大小，就需要用到堆（。堆也被称为动态内存，使用堆内存意味着动态内存分配。（内存中的栈实际就是数据结构中的栈的一种实现，但此处的堆不是数据结构中所说的堆，而是内存的空闲池）。

  • 动态内存涉及C语言中四个函数：malloc、calloc、realloc、free，在C++中对应的操作符是new和delete，由于C++向后兼容C（C++是C的超集），因此在C++中也可以使用前四个函数 。

  • malloc返回void指针，返回时需要对其进行强制类型转换。

  • 如果用malloc分配了一些动态内存，用完了就要释放，否则就会造成内存泄漏，内存是非常重要的资源 。任何在堆上分配的 内存，在函数调用结束后并不会像栈那样自动释放，也不需要像全局变量一样在程序的整个生命周期内一直存活。 先来看一段代码：

函数指针

  • 函数指针用来存储函数的地址。指针可以指向数据（包括变量和常量），还可以用来指向函数。可以用函数指针来解引用和执行函数。

  • 函数的地址是什么？——首先理解核心逻辑，程序是一组顺序的计算机指令集合，最终由编译器编码为二进制机器码执行。代码段用来存放可执行文件拷贝过来的机器码或指令，指令需要从第二存储介质（比如磁盘）拷贝到主存才能执行。内存不仅用来存储指令，还需要存储放运行期间产生的很多数据。其他区段就是用来存储和管理数据的。

  • 观察代码段，指令一般是顺序执行，除非需要跳转到某一条指令，比如函数调用。一个函数就是一组存储在连续内存块中的指令。函数的地址也称为函数的入口点。函数指针实际存放了函数在内存中的起始地址或入口点。
